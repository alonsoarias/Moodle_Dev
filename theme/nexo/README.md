# Nexo Theme

Nexo is a Moodle child theme tailored for the Instituto Superior de Educación Rural (ISER). The theme keeps all
features of the original Inteb theme while updating the branding, credits, and institutional information for the
Vicerrectoría Académica.

## Features

- Responsive design with extensive customization options
- Login carousel system
- Role-based copy/paste prevention
- Integrated chat (Tawk.to)
- Custom headers for dashboard and course listings
- Global notification banner
- Custom footer sections
- Dark/Light mode support
- Accessibility controls

## Installation

### Via ZIP Upload

1. Log in to Moodle as an administrator.
2. Go to *Site administration > Plugins > Install plugins*.
3. Upload the ZIP package for the theme.
4. Follow the installation prompts.

### Manual Installation

1. Extract the theme files into `{your/moodle/dirroot}/theme/nexo`.
2. Access *Site administration > Notifications* to complete the installation.
3. Alternatively run `php admin/cli/upgrade.php` from the command line.

## Configuration

Theme settings are located under *Site administration > Appearance > Themes > Nexo*:

- General configuration
- Login page carousel
- Header/footer options
- Chat integration
- Copy/paste prevention
- Custom CSS

## Requirements

- Moodle 4.0 or higher
- Theme RemUI installed
- PHP 8.0+
