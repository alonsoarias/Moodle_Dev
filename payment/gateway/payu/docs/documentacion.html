Pasarela de pagos lider en Latinoamerica integrada con tu plataforma educativa

v1.0.0 Moodle 4.1+ Colombia

1 Introduccion

Plugin de pasarela de pago PayU para Moodle, disenado especificamente para el mercado colombiano. Permite monetizar cursos con la plataforma de pagos lider en Latinoamerica.

💳

Multiples Metodos

Tarjetas, PSE, Efecty, Baloto, Su Red y mas metodos locales.

🔒

Seguridad MD5

Firma MD5 para transacciones y validacion de respuestas.

🔄

WebCheckout

Redireccion segura a la plataforma de PayU.

Colombia

Optimizado para el mercado colombiano en COP y USD.

🧪

Sandbox

Credenciales de prueba automaticas para testing.

📧

Notificaciones

Emails automaticos sobre el estado de los pagos.

Por que PayU?

  • Lider en Latinoamerica - Mas de 20 anos de experiencia en pagos digitales
  • Pagos en efectivo - Efecty, Baloto, Su Red y corresponsales
  • PSE - Conecta con todos los bancos de Colombia
  • Tarjetas internacionales - Visa, Mastercard, Amex, Diners

3 Instalacion del Plugin

Instalacion Manual

  1. Descarga el plugin

    Descarga el ZIP desde el repositorio o contacta a soporte@ingeweb.co

  2. Extrae los archivos

    Descomprime en el directorio:

    /tu-moodle/payment/gateway/payu
  3. Ejecuta la instalacion

    Ve a: Administracion del sitio → Notificaciones

Via Git

# Navegar al directorio
cd /ruta/a/moodle/payment/gateway

# Clonar repositorio
git clone https://github.com/ingeweb/moodle-paygw_payu.git payu

# Actualizar Moodle
php /ruta/a/moodle/admin/cli/upgrade.php

11 Seguridad

Firma MD5

// Envio
signature = MD5(apiKey~merchantId~referenceCode~amount~currency)

// Confirmacion
signature = MD5(apiKey~merchantId~referenceCode~value~currency~state_pol)
  • HTTPS obligatorio para procesar pagos
  • API Key protegida - nunca compartir
  • Validar firmas en todas las transacciones

12 Solucion de Problemas

Error de firma invalida
  1. Verifica que el API Key sea exactamente igual al del panel de PayU
  2. Confirma el ambiente correcto (sandbox/produccion)
  3. Revisa el formato del valor (decimales)
Usuario no se inscribe
  1. Verifica la URL de confirmacion en PayU
  2. Revisa los logs de Moodle
  3. Verifica la tabla paygw_payu_transactions

13 Referencia API

Clase payu_helper

use paygw_payu\payu_helper;

// Crear instancia
$helper = payu_helper::from_config($config);

// Generar firma
$signature = $helper->generate_signature($reference, $amount, $currency);

// Verificar firma
$valid = $helper->verify_signature($sign, $reference, $value, $currency, $state);

// Verificar aprobado
if ($helper->is_approved($state_pol)) {
    // Pago aprobado
}
