Introduccion

Plugin de pasarela de pago PayU para Moodle, diseado especificamente para el mercado colombiano. Permite monetizar cursos con la plataforma de pagos lider en Latinoamerica.

💳

Multiples Metodos

Tarjetas de credito/debito, PSE, Efecty, Baloto, Su Red y mas.

🔒

Seguridad MD5

Firma MD5 para transacciones, validacion de respuestas, antifraude.

🔄

WebCheckout

Redireccion segura a la plataforma de pago de PayU.

Colombia

Optimizado exclusivamente para el mercado colombiano en COP y USD.

🧪

Sandbox Automatico

Credenciales de prueba automaticas para desarrollo y testing.

📧

Notificaciones

Alertas automaticas por email sobre el estado de los pagos.

Por que PayU?

  • Lider en Latinoamerica - Mas de 20 anos de experiencia en pagos digitales
  • Pagos en efectivo - Acepta pagos via Efecty, Baloto, Su Red y corresponsales
  • Todos los bancos - PSE conecta con todos los bancos de Colombia
  • Tarjetas internacionales - Visa, Mastercard, American Express, Diners Club
  • Soporte local - Equipo de soporte en Colombia

Caracteristicas Principales

  • Soporte para ambientes Sandbox (pruebas) y Produccion
  • Redireccion a WebCheckout de PayU para procesamiento seguro
  • Pagina de confirmacion (callback) para actualizar transacciones
  • Pagina de respuesta para mostrar resultado al usuario
  • Notificaciones automaticas a usuarios por email
  • Registro completo de transacciones en base de datos
  • Cumplimiento GDPR para proteccion de datos personales
  • Soporte multiidioma (Espanol e Ingles)
  • Credenciales de prueba automaticas en Sandbox

Instalacion del Plugin

Metodo 1: Instalacion Manual

  1. Descarga el plugin

    Descarga el archivo ZIP desde el repositorio oficial o contacta a soporte@ingeweb.co

  2. Extrae los archivos

    Descomprime el archivo en el directorio de pasarelas de pago de Moodle:

    /tu-sitio-moodle/payment/gateway/payu
  3. Verifica la estructura de archivos

    Asegurate de que la estructura sea correcta:

    payment/gateway/payu/
├── classes/
│   ├── gateway.php           # Clase principal
│   ├── payu_helper.php       # Helper de API
│   └── privacy/
│       └── provider.php      # GDPR
├── db/
│   ├── install.xml           # Estructura BD
│   └── messages.php          # Notificaciones
├── docs/
│   └── documentacion.html    # Esta guia
├── lang/
│   ├── en/paygw_payu.php     # Ingles
│   └── es/paygw_payu.php     # Espanol
├── pix/
│   └── icon.svg              # Icono
├── callback.php              # Confirmacion PayU
├── CHANGELOG.md
├── lib.php
├── pay.php                   # Inicio de pago
├── README.md
├── return.php                # Respuesta usuario
└── version.php
  4. Ejecuta la instalacion en Moodle

    Accede como administrador y ve a:

    Administracion del sitio → Notificaciones

    Moodle detectara automaticamente el nuevo plugin y te guiara en la instalacion.

  5. Verifica la instalacion

    Confirma que el plugin aparece en:

    Administracion del sitio → Plugins → Pasarelas de pago → Gestionar pasarelas

# Navegar al directorio de pasarelas de pago

Configuracion en PayU

Antes de configurar el plugin en Moodle, necesitas obtener tus credenciales de PayU y configurar las URLs de callback.

Paso 1: Obtener Credenciales de API

  1. Accede al panel de PayU

    Inicia sesion en merchants.payulatam.com

  2. Ve a Configuracion Tecnica

    Navega a Configuracion → Configuracion tecnica

  3. Copia las credenciales

    Encontraras los siguientes datos:

Credencial Descripcion Ubicacion en PayU
Merchant ID Identificador unico del comercio Configuracion → Datos tecnicos
Account ID ID de cuenta para Colombia Configuracion → Cuentas
API Key Llave secreta para firmar transacciones Configuracion → Datos tecnicos
API Login Usuario de API para consultas Configuracion → Datos tecnicos

Paso 2: Configurar URLs de Callback

En el panel de PayU, configura las siguientes URLs:

URL Valor Funcion
URL de Confirmacion https://tu-sitio.com/payment/gateway/payu/callback.php Recibe notificacion de PayU sobre el estado del pago
URL de Respuesta https://tu-sitio.com/payment/gateway/payu/return.php Redirige al usuario despues del pago

⚠️ Seguridad de las Credenciales

  • Nunca compartas tu API Key con nadie
  • No la incluyas en codigo fuente publico
  • Usa las credenciales correctas para cada ambiente (sandbox/produccion)
  • Regenerala si sospechas que fue comprometida

Configuracion del Callback

El callback es la URL donde PayU envia notificaciones sobre el estado de las transacciones. Es esencial para procesar pagos asincronos y pagos en efectivo.

Como Funciona el Flujo

  1. Usuario inicia el pago

    El usuario es redirigido a PayU WebCheckout

  2. Usuario completa el pago

    Ingresa sus datos y procesa el pago en PayU

  3. PayU procesa la transaccion

    Valida los datos y procesa el pago con el banco

  4. PayU notifica via Callback

    Envia una solicitud POST a tu URL de confirmacion con los datos del pago

  5. Plugin valida y procesa

    Verifica la firma MD5, actualiza la transaccion e inscribe al usuario

  6. Usuario es redirigido

    Es enviado a la pagina de respuesta con el resultado

URLs de Callback

💡 URLs para tu sitio

URL de Confirmacion:

https://[TU-DOMINIO]/payment/gateway/payu/callback.php

URL de Respuesta:

https://[TU-DOMINIO]/payment/gateway/payu/return.php

Verificar el Callback

  • Asegurate de que las URLs esten configuradas en el panel de PayU
  • Verifica que tu servidor permita conexiones entrantes desde PayU
  • Las URLs deben ser accesibles via HTTPS
  • Prueba con un pago sandbox para verificar que funciona

✅ Callback Configurado Correctamente

Sabras que el callback funciona si:

  • Los pagos con tarjeta inscriben automaticamente al usuario
  • La transaccion en la BD cambia de PENDING a APPROVED/DELIVERED
  • El usuario recibe email de confirmacion
  • Los pagos en efectivo se procesan cuando el usuario paga

Guia para Administradores

Configurar Pago en un Curso

  1. Accede al curso

    Navega al curso donde deseas habilitar pagos.

  2. Ve a Metodos de inscripcion

    Accede a: Administracion del curso → Usuarios → Metodos de inscripcion

  3. Agrega inscripcion con pago

    Haz clic en "Agregar metodo" y selecciona "Inscripcion con pago"

  4. Configura el metodo de pago
    • Cuenta de pago: Selecciona la cuenta donde configuraste PayU
    • Costo de inscripcion: Ingresa el precio (ej: 50000 para COP, 25 para USD)
    • Moneda: COP o USD
  5. Guarda los cambios

    El curso ahora requerira pago para inscribirse.

Guia para Estudiantes

Como Pagar e Inscribirse a un Curso

  1. Accede al curso

    Navega al curso que deseas tomar. Veras el precio y el boton de pago.

  2. Haz clic en "Pagar con PayU"

    Seras redirigido a la plataforma segura de PayU.

  3. Selecciona tu metodo de pago

    Elige entre tarjeta de credito, PSE, Efecty, Baloto, etc.

  4. Completa la informacion requerida

    Segun el metodo seleccionado, ingresa los datos solicitados.

  5. Confirma el pago

    Sigue las instrucciones especificas del metodo de pago.

  6. Espera la confirmacion

    Para pagos inmediatos, seras inscrito al instante. Para pagos en efectivo, espera hasta que realices el pago en el punto autorizado.

Metodos de Pago - Instrucciones

💳 Tarjeta de Credito/Debito

Ingresa el numero de tarjeta, fecha de vencimiento, CVV y nombre del titular. El pago se procesa instantaneamente.

🏦 PSE

Selecciona tu banco, tipo de persona (natural/juridica) y seras redirigido al portal de tu banco para completar la transferencia.

💵 Efecty / Baloto

Recibiras un comprobante con un codigo. Acude a cualquier punto Efecty o Baloto, presenta el codigo y paga en efectivo.

💵 Su Red

Similar a Efecty, recibiras un codigo que puedes pagar en corresponsales bancarios y puntos Su Red.

✅ Confirmacion de Pago

Una vez aprobado el pago:

  • Seras inscrito automaticamente al curso
  • Recibiras un email de confirmacion
  • Podras acceder inmediatamente al contenido del curso

Seguridad

Firma MD5 de Envio

Todas las transacciones son firmadas para garantizar su integridad:

signature = MD5(apiKey~merchantId~referenceCode~amount~currency)

Firma MD5 de Confirmacion

Las respuestas de PayU se validan con:

signature = MD5(apiKey~merchantId~referenceCode~value~currency~state_pol)

💡 Formato del Valor

PayU tiene reglas especificas para el formato del valor en la firma:

  • Si el segundo decimal es 0: usar un solo decimal (ej: 150000.0)
  • Si el segundo decimal es diferente de 0: usar dos decimales (ej: 150000.50)

Mejores Practicas de Seguridad

  • Usa HTTPS siempre - Obligatorio para procesar pagos
  • Protege tu API Key - Nunca la compartas o publiques
  • Valida todas las firmas - Rechaza transacciones con firmas invalidas
  • Monitorea transacciones - Revisa regularmente los logs
  • Actualiza el plugin - Mantente al dia con las actualizaciones

🔒 Cumplimiento de Seguridad

  • PCI DSS: PayU cumple con los estandares de seguridad de la industria de tarjetas
  • GDPR: El plugin incluye provider de privacidad para proteccion de datos
  • Sin datos sensibles: El plugin no almacena numeros de tarjeta ni datos sensibles

Solucion de Problemas

Error de firma invalida
  1. Verifica que el API Key sea exactamente igual al del panel de PayU
  2. Confirma que estas usando las credenciales del ambiente correcto
  3. Revisa que el Merchant ID y Account ID sean correctos
  4. Verifica el formato del valor (decimales)
El usuario no se inscribe despues del pago
  1. Verifica que la URL de confirmacion este configurada en PayU
  2. Confirma que tu servidor permita conexiones entrantes
  3. Revisa los logs de Moodle por errores
  4. Verifica la tabla paygw_payu_transactions para ver el estado
El pago no se procesa
  1. Verifica que las credenciales sean correctas
  2. Confirma que el ambiente seleccionado coincida con las credenciales
  3. Revisa la consola del navegador por errores JavaScript
  4. Verifica que el servidor tenga cURL habilitado
Transaccion queda en PENDING
  1. Esto es normal para pagos en efectivo y PSE
  2. Verifica que el callback este configurado
  3. Para pagos en efectivo, el usuario debe pagar en el punto autorizado
  4. Puedes verificar el estado en el panel de PayU

Referencia de API

Clase payu_helper

use paygw_payu\payu_helper;

// Crear instancia desde configuracion
$helper = payu_helper::from_config($config);

// Generar firma de envio
$signature = $helper->generate_signature($reference, $amount, $currency);

// Verificar firma de respuesta
$valid = $helper->verify_signature($sign, $reference, $value, $currency, $state);

// Verificar si esta aprobado
if ($helper->is_approved($state_pol)) {
    // Pago aprobado
}

// Entregar orden (inscribir usuario)
$helper->deliver_order($component, $paymentarea, $itemid, $paymentid, $userid);

Clase gateway

use paygw_payu\gateway;

// Obtener monedas soportadas
$currencies = gateway::get_supported_currencies(); // ['COP', 'USD']

// Obtener credenciales de prueba
$test_creds = gateway::get_test_credentials();

payu_helper::STATE_APPROVED  // 4

payu_helper::STATE_DECLINED  // 6
payu_helper::STATE_PENDING   // 7
payu_helper::STATE_ERROR     // 104
