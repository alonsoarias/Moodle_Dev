Instalación

Descargar el Plugin

Descargue el plugin desde el repositorio o clone via Git:

git clone https://github.com/ingeweb/paygw_payu.git payment/gateway/payu

Instalar en Moodle

Copie la carpeta payu a /payment/gateway/ de su instalación de Moodle y visite la página de administración para completar la instalación.

Configurar Cuenta de Pago

Vaya a Administración del sitio > Plugins > Pasarelas de pago > Gestionar cuentas de pago y cree una nueva cuenta seleccionando PayU Colombia.

Configuración

Credenciales de PayU

Obtenga sus credenciales desde el panel de comercios de PayU:

URLs de Callback

Configure estas URLs en el panel de PayU:

URL de Confirmación: https://su-sitio.com/payment/gateway/payu/callback.php URL de Respuesta: https://su-sitio.com/payment/gateway/payu/return.php

Flujo de Pago

1. Usuario inicia pago en Moodle → 2. Redirección a PayU WebCheckout → 3. Usuario completa pago → 4. PayU envía confirmación → 5. Moodle entrega el contenido

Referencia API

Clase payu_helper

use paygw_payu\payu_helper; // Crear instancia desde configuración $helper = payu_helper::from_config($config); // Generar firma de envío $signature = $helper->generate_signature($reference, $amount, $currency); // Verificar firma de respuesta $valid = $helper->verify_signature($sign, $reference, $value, $currency, $state); // Verificar estado de transacción if ($helper->is_approved($state_pol)) { // Pago aprobado }

Firma de Envío

MD5(apiKey~merchantId~referenceCode~amount~currency)

Firma de Confirmación

MD5(apiKey~merchantId~referenceCode~value~currency~state_pol)

Solución de Problemas

Firma inválida: Verifique que el API Key sea correcto y que esté usando el ambiente correcto (sandbox/producción).
No se procesa el pago: Asegúrese de que las URLs de callback estén correctamente configuradas en PayU y que su servidor permita conexiones entrantes.
Usuario no inscrito: Revise los logs de Moodle y la tabla paygw_payu_transactions para verificar el estado de la transacción.
