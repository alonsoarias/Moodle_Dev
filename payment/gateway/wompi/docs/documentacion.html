1 Introducción

El plugin Wompi Payment Gateway permite a los sitios Moodle aceptar pagos a través de Wompi, la plataforma líder de pagos en Colombia, subsidiaria de Bancolombia. Soporta múltiples métodos de pago locales adaptados al mercado colombiano.

💳

Múltiples Métodos de Pago

Tarjetas, Nequi, PSE, Bancolombia, Daviplata y Puntos Colombia.

🔒

Seguridad Avanzada

Firma SHA256, verificación de webhooks y validación de llaves.

⚡

Procesamiento Asíncrono

Webhooks para pagos que requieren confirmación diferida.

🌐

Multiidioma

Soporte completo en Español e Inglés con cumplimiento GDPR.

Características Principales

  • Soporte para ambientes Sandbox (pruebas) y Producción
  • Widget de checkout integrado de Wompi
  • Procesamiento de pagos asíncronos vía webhooks
  • Notificaciones automáticas a usuarios
  • Registro completo de transacciones
  • Cumplimiento GDPR para protección de datos

3 Instalación del Plugin

Método 1: Instalación Manual

  1. Descarga el plugin

    Descarga el archivo ZIP del plugin desde el repositorio oficial o desde ingeweb.co

  2. Extrae los archivos

    Descomprime el archivo y coloca la carpeta wompi en:

    /tu-sitio-moodle/payment/gateway/wompi
  3. Verifica la estructura

    Asegúrate de que los archivos estén correctamente ubicados:

    payment/gateway/wompi/
├── classes/
│   ├── gateway.php
│   ├── wompi_helper.php
│   └── privacy/provider.php
├── db/
│   ├── install.xml
│   └── messages.php
├── lang/
│   ├── en/paygw_wompi.php
│   └── es/paygw_wompi.php
├── pix/icon.svg
├── pay.php
├── process.php
├── webhook.php
└── version.php
  4. Completa la instalación

    Accede a tu sitio Moodle como administrador y navega a:

    Administración del sitio → Notificaciones

    Moodle detectará el nuevo plugin y te guiará para completar la instalación.

Método 2: Via línea de comandos

# Navegar al directorio de pasarelas de pago
cd /ruta/a/moodle/payment/gateway

# Clonar el repositorio
git clone https://github.com/ingeweb/moodle-paygw_wompi.git wompi

# Ejecutar actualización de Moodle
php /ruta/a/moodle/admin/cli/upgrade.php

✅ Verificación

Después de la instalación, verifica que el plugin aparezca en Administración del sitio → Plugins → Pasarelas de pago

4 Configuración en Wompi

Antes de configurar el plugin en Moodle, necesitas obtener tus credenciales del panel de Wompi.

Obtener Credenciales

  1. Accede al Dashboard de Wompi

    Ingresa a comercios.wompi.co con tu cuenta de comercio.

  2. Navega a Configuración de Llaves

    Ve a Configuración → Llaves de API en el menú lateral.

  3. Copia las llaves necesarias

    Necesitarás las siguientes llaves:

Llave Sandbox Producción Uso
Llave Pública pub_test_... pub_prod_... Iniciar transacciones
Llave Privada prv_test_... prv_prod_... Consultar transacciones
Llave de Integridad Cadena alfanumérica Firmar transacciones
Llave de Eventos Cadena alfanumérica Verificar webhooks

⚠️ Seguridad de las Llaves

Nunca compartas tus llaves privadas. Guárdalas en un lugar seguro y no las expongas en código público.

5 Configuración en Moodle

Crear Cuenta de Pago

  1. Accede a la gestión de cuentas de pago

    Ve a Administración del sitio → Plugins → Pasarelas de pago → Gestionar cuentas de pago

  2. Crea una nueva cuenta

    Haz clic en "Crear cuenta de pago" e ingresa un nombre descriptivo (ej: "Pagos Colombia - Wompi").

  3. Habilita la pasarela Wompi

    En la sección de pasarelas disponibles, activa Wompi.

Configurar Credenciales

Ambiente

  • Sandbox: Para pruebas y desarrollo (usa llaves pub_test_ y prv_test_)
  • Producción: Para pagos reales (usa llaves pub_prod_ y prv_prod_)

Credenciales API

  • Llave Pública: Tu llave pública de Wompi
  • Llave Privada: Tu llave privada de Wompi
  • Llave de Integridad: Para firmar las transacciones
  • Llave de Eventos: (Opcional) Para verificar webhooks

💡 Consejo

Comienza siempre en modo Sandbox para probar la integración antes de pasar a producción.

7 Configuración del Webhook

El webhook es esencial para procesar pagos asíncronos como PSE, Nequi y Bancolombia.

Configurar en Wompi

  1. Accede a la configuración de eventos

    En el Dashboard de Wompi, ve a Configuración → Eventos.

  2. Agrega la URL del webhook

    Ingresa la siguiente URL (reemplaza con tu dominio):

    https://tu-sitio-moodle.com/payment/gateway/wompi/webhook.php
  3. Selecciona los eventos

    Activa el evento transaction.updated para recibir notificaciones.

  4. Copia la Llave de Eventos

    Wompi generará una Llave de Eventos. Cópiala y agrégala en la configuración del plugin.

✅ Verificar Webhook

Puedes verificar que funciona haciendo una compra de prueba en modo Sandbox con Nequi o PSE.

Estructura del Evento

{
  "event": "transaction.updated",
  "data": {
    "transaction": {
      "id": "123456-789-abc",
      "status": "APPROVED",
      "reference": "enrol_fee_course_1_123_1702800000",
      "amount_in_cents": 5000000
    }
  },
  "timestamp": 1702800000,
  "signature": {
    "checksum": "abc123...",
    "properties": ["data.transaction.id", "data.transaction.status"]
  }
}

8 Guía para Administradores

Configurar Inscripción de Pago en un Curso

  1. Accede al curso

    Navega al curso donde deseas activar la inscripción de pago.

  2. Configura el método de inscripción

    Ve a Participantes → Métodos de inscripción y agrega "Inscripción con pago".

  3. Selecciona la cuenta de pago

    Elige la cuenta de pago donde configuraste Wompi.

  4. Establece el precio

    Ingresa el costo de inscripción en COP (Pesos Colombianos).

    Ejemplo: 50000 = $50.000 COP
  5. Guarda los cambios

    El curso ahora mostrará el botón de pago a los usuarios no inscritos.

Monitorear Transacciones

En Moodle

  • Reportes de pago: Administración del sitio → Reportes → Pagos
  • Logs del sistema: Administración del sitio → Reportes → Logs

En Wompi

  • Dashboard de comercio → Transacciones
  • Filtra por referencia para encontrar transacciones específicas

💡 Referencias de Transacción

Las referencias siguen el formato: componente_area_itemid_userid_timestamp
Ejemplo: enrol_fee_course_15_123_1702800000

9 Guía para Estudiantes

El proceso de pago es sencillo e intuitivo:

  1. Accede al curso

    Navega al curso que requiere pago para inscribirte.

  2. Haz clic en el botón de pago

    Verás la información del curso y el costo. Haz clic en "Pagar con Wompi".

  3. Selecciona tu método de pago

    El widget de Wompi se abrirá mostrando los métodos disponibles.

  4. Completa el pago

    Sigue las instrucciones según el método elegido:

    • Tarjeta: Ingresa los datos de tu tarjeta
    • Nequi: Ingresa tu número de celular y aprueba en la app
    • PSE: Selecciona tu banco y completa en la página del banco
  5. Espera la confirmación

    Una vez aprobado el pago, serás inscrito automáticamente al curso.

✅ Confirmación

Recibirás un correo electrónico confirmando tu inscripción al curso una vez procesado el pago.

⚠️ Antes de Producción

Asegúrate de:

  • Probar todos los métodos de pago que habilitarás
  • Verificar que el webhook funciona correctamente
  • Confirmar que las inscripciones se completan automáticamente
  • Cambiar las llaves de Sandbox por las de Producción
  • Cambiar el ambiente a "Producción" en la configuración del plugin

11 Solución de Problemas

El pago no se procesa
  1. Verifica que las llaves sean correctas para el ambiente seleccionado
  2. Confirma que el prefijo coincida (pub_test_ para Sandbox, pub_prod_ para Producción)
  3. Revisa los logs de Moodle en Administración del sitio → Reportes → Logs
  4. Verifica que tu servidor tenga conexión a Internet
Error de firma de integridad
  1. Verifica que la Llave de Integridad sea exactamente la del Dashboard de Wompi
  2. Asegúrate de que no haya espacios adicionales en las llaves
  3. Confirma que estás usando la llave del ambiente correcto
El usuario no se inscribe después del pago
  1. Verifica que el webhook esté configurado correctamente en Wompi
  2. Confirma que la URL del webhook sea accesible (HTTPS)
  3. Revisa que la Llave de Eventos esté configurada en Moodle
  4. Para pagos con tarjeta, verifica que la redirección funcione
El widget de Wompi no carga
  1. Verifica que tu sitio use HTTPS
  2. Revisa la consola del navegador (F12) por errores JavaScript
  3. Asegúrate de que no haya bloqueadores de scripts activos
  4. Confirma que la Llave Pública sea válida
Los métodos de pago no aparecen en el widget
  1. Verifica que hayas habilitado los métodos en la configuración del plugin
  2. Confirma que tu cuenta de Wompi tenga habilitados esos métodos
  3. Algunos métodos requieren verificación adicional en Wompi

Logs y Diagnóstico

  • Logs de Moodle: Administración del sitio → Reportes → Logs (filtra por "paygw_wompi")
  • Logs del servidor: Revisa los logs de error de PHP
  • Dashboard de Wompi: Sección de transacciones y eventos
