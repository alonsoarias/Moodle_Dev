Introducción

Plugin de pasarela de pago Wompi para Moodle, diseñado específicamente para el mercado colombiano.

💳

Múltiples Métodos

Tarjetas, Nequi, PSE, Bancolombia, Daviplata y Puntos Colombia.

🔒

Seguridad Avanzada

Firma SHA256, verificación de webhooks y validación de llaves.

⚡

Pagos Asíncronos

Webhooks para pagos que requieren confirmación diferida.

Características

  • Soporte para ambientes Sandbox y Producción
  • Widget de checkout integrado de Wompi
  • Procesamiento de pagos asíncronos vía webhooks
  • Notificaciones automáticas a usuarios
  • Registro completo de transacciones
  • Cumplimiento GDPR para protección de datos
  • Soporte multiidioma (Español e Inglés)

2 Instalación del Plugin

Método Manual

  1. Descarga el plugin

    Desde el repositorio oficial o ingeweb.co

  2. Extrae los archivos 
    /tu-sitio-moodle/payment/gateway/wompi
  3. Verifica la estructura 
    payment/gateway/wompi/
├── classes/
│   ├── gateway.php
│   ├── wompi_helper.php
│   └── privacy/provider.php
├── db/
├── lang/
├── pix/
├── pay.php
├── process.php
├── webhook.php
└── version.php
  4. Completa en Moodle

    Administración del sitio → Notificaciones

Via Git

cd /ruta/a/moodle/payment/gateway
git clone https://github.com/ingeweb/moodle-paygw_wompi.git wompi
php /ruta/a/moodle/admin/cli/upgrade.php

✅ Verificación

Confirma en Administración → Plugins → Pasarelas de pago

3 Configuración en Wompi

  1. Accede al Dashboard

    comercios.wompi.co

  2. Ve a Llaves de API

    Configuración → Llaves de API

  3. Copia las llaves
LlaveSandboxProducciónUso
Públicapub_test_...pub_prod_...Iniciar pagos
Privadaprv_test_...prv_prod_...Consultar
IntegridadAlfanuméricaFirmar
EventosAlfanuméricaWebhooks

⚠️ Seguridad

Nunca compartas tus llaves privadas.

4 Configuración en Moodle

  1. Gestionar cuentas de pago

    Administración → Plugins → Pasarelas de pago → Gestionar cuentas

  2. Crear cuenta de pago

    Nombre: "Pagos Colombia - Wompi"

  3. Habilitar Wompi

    Activa la pasarela e ingresa las credenciales

Credenciales

  • Ambiente: Sandbox o Producción
  • Llave Pública: Tu llave pública
  • Llave Privada: Tu llave privada
  • Integridad: Para firmar transacciones
  • Eventos: Para webhooks (opcional)

💡 Consejo

Empieza en Sandbox para probar antes de producción.

6 Configuración del Webhook

Esencial para pagos asíncronos (PSE, Nequi, Bancolombia).

  1. En Dashboard Wompi

    Configuración → Eventos

  2. Agregar URL 
    https://tu-sitio.com/payment/gateway/wompi/webhook.php
  3. Activar evento

    transaction.updated

  4. Copiar Llave de Eventos

    Agregarla en configuración del plugin

✅ Verificar

Prueba con Nequi o PSE en Sandbox.

7 Guía para Administradores

Configurar Pago en Curso

  1. Ir al curso

    Navega al curso deseado

  2. Métodos de inscripción

    Participantes → Métodos de inscripción → Agregar "Inscripción con pago"

  3. Seleccionar cuenta

    Elige la cuenta con Wompi

  4. Establecer precio

    En COP (ej: 50000 = $50.000)

Monitorear Transacciones

En Moodle

  • Administración → Reportes → Pagos
  • Administración → Reportes → Logs

En Wompi

  • Dashboard → Transacciones
  • Filtrar por referencia

10 Solución de Problemas

El pago no se procesa
  1. Verificar llaves correctas para el ambiente
  2. Confirmar prefijos (pub_test_ / pub_prod_)
  3. Revisar logs de Moodle
Error de firma de integridad
  1. Verificar Llave de Integridad exacta
  2. Sin espacios adicionales
  3. Ambiente correcto
Usuario no se inscribe
  1. Verificar webhook configurado
  2. URL accesible (HTTPS)
  3. Llave de Eventos configurada
Widget no carga
  1. Sitio con HTTPS
  2. Revisar consola (F12)
  3. Sin bloqueadores de scripts
