1 Introduccion

Plugin de pasarela de pago Wompi para Moodle, disenado especificamente para el mercado colombiano. Permite monetizar cursos con la plataforma oficial de pagos de Bancolombia.

💳

Multiples Metodos

Tarjetas, Nequi, PSE, Bancolombia, Daviplata y Puntos Colombia.

🔒

Seguridad SHA256

Firma de integridad y verificacion de webhooks.

⚡

Pagos Asincronos

Webhooks para PSE, Nequi y pagos que requieren confirmacion.

Colombia

Optimizado exclusivamente para el mercado colombiano en COP.

🧪

Sandbox Automatico

Credenciales de prueba automaticas para testing.

📧

Notificaciones

Emails automaticos sobre el estado de los pagos.

Por que Wompi?

  • Respaldo de Bancolombia - Plataforma oficial del banco mas grande de Colombia
  • Sin costos de integracion - Solo pagas por transaccion exitosa
  • Metodos locales - Nequi, PSE, Daviplata y billeteras colombianas
  • Widget moderno - Experiencia de pago fluida y responsiva

3 Instalacion del Plugin

Instalacion Manual

  1. Descarga el plugin

    Descarga el ZIP desde el repositorio o contacta a soporte@ingeweb.co

  2. Extrae los archivos

    Descomprime en el directorio:

  3. Verifica la estructura 
    payment/gateway/wompi/

│   ├── wompi_helper.php      # Helper de API
│   └── privacy/provider.php  # GDPR

├── lang/

    Ve a: Administracion del sitio → Notificaciones

7 Webhook

El webhook es esencial para procesar pagos asincronos como PSE, Nequi, Bancolombia Transfer, etc.

  1. Accede al Dashboard de Wompi

    Inicia sesion en comercios.wompi.co

  2. Ve a Configuracion → Eventos

    Agrega la URL del webhook de tu sitio

  3. Activa transaction.updated

    Selecciona el evento para recibir notificaciones

  4. Copia la Llave de Eventos

    Agregala en la configuracion del plugin en Moodle

💡 URL del Webhook

https://[TU-DOMINIO]/payment/gateway/wompi/webhook.php

✅ Webhook Funcionando

  • Pagos con Nequi/PSE inscriben automaticamente
  • La transaccion cambia de PENDING a APPROVED
  • El usuario recibe email de confirmacion

8 Guia para Administradores

Configurar Pago en un Curso

  1. Accede al curso

    Navega al curso donde deseas habilitar pagos.

  2. Metodos de inscripcion

    Ve a: Administracion del curso → Usuarios → Metodos de inscripcion

  3. Agregar inscripcion con pago

    Selecciona la cuenta Wompi, precio (en COP) y guarda.

9 Guia para Estudiantes

  1. Accede al curso

    Navega al curso y veras el precio.

  2. Pagar con Wompi

    Se abrira el widget de Wompi.

  3. Selecciona metodo

    Elige tarjeta, Nequi, PSE, Bancolombia, etc.

  4. Confirma el pago

    Sigue las instrucciones del metodo.

💳 Tarjeta

Ingresa numero, fecha, CVV y nombre. Pago instantaneo.

📱 Nequi

Ingresa tu celular. Aprueba en la app Nequi.

🏦 PSE

Selecciona tu banco y completa la transferencia.

🔄 Bancolombia

Escanea el QR o transfiere desde la app.

✅ Confirmacion

Una vez aprobado el pago, seras inscrito automaticamente y recibiras un email.

11 Seguridad

Firma de Integridad SHA256

signature = SHA256(reference + amount_in_cents + currency + integrity_key)

Verificacion de Webhooks

// Concatenar propiedades segun signature.properties
$signature_string = '';
foreach ($properties as $property) {
    $signature_string .= get_nested_value($event_data, $property);
}
$signature_string .= $timestamp . $events_key;
$calculated = hash('sha256', $signature_string);
  • HTTPS obligatorio para procesar pagos
  • Llaves protegidas - nunca compartir
  • Verificar firmas en todas las transacciones
  • PCI DSS - Wompi cumple con estandares de seguridad

12 Solucion de Problemas

El pago no se procesa
  1. Verifica que las llaves sean correctas para el ambiente
  2. Confirma los prefijos (pub_test_ para Sandbox)
  3. Revisa los logs de Moodle
Error de firma de integridad
  1. Verifica la Llave de Integridad exacta (sin espacios)
  2. Confirma el ambiente correcto
  3. Regenera la llave en Wompi si es necesario
Usuario no se inscribe
  1. Verifica el webhook en Wompi
  2. Confirma URL accesible (HTTPS)
  3. Revisa la tabla paygw_wompi_transactions
Widget no carga
  1. Verifica HTTPS en tu sitio
  2. Revisa la consola del navegador
  3. Desactiva bloqueadores de scripts

13 Referencia API

Clase wompi_helper

use paygw_wompi\wompi_helper;

// Crear instancia
$helper = new wompi_helper($publickey, $privatekey, $integritykey, $environment, $eventskey);

// Generar firma
$signature = $helper->generate_integrity_signature($reference, $amount_cents, $currency);

// Obtener transaccion
$transaction = $helper->get_transaction($transaction_id);

// Verificar webhook
$valid = $helper->verify_webhook_signature($event_data, $signature);

// Entregar orden
$helper->deliver_order($component, $paymentarea, $itemid, $userid, $cost, $currency);

Clase gateway

use paygw_wompi\gateway;

// Monedas soportadas
$currencies = gateway::get_supported_currencies(); // ['COP']

// URL de API
$url = gateway::get_api_url('sandbox'); // https://sandbox.wompi.co/v1

// Credenciales de prueba
$creds = gateway::get_test_credentials();

// Crear helper desde config
$helper = gateway::create_helper_from_config($config);

Constantes de Estado

wompi_helper::STATUS_APPROVED   // 'APPROVED'
wompi_helper::STATUS_DECLINED   // 'DECLINED'
wompi_helper::STATUS_PENDING    // 'PENDING'
wompi_helper::STATUS_VOIDED     // 'VOIDED'
wompi_helper::STATUS_ERROR      // 'ERROR'
