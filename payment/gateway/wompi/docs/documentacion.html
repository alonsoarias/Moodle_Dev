Introduccion

Plugin de pasarela de pago Wompi para Moodle, diseado especificamente para el mercado colombiano. Permite monetizar cursos aceptando multiples metodos de pago locales.

💳

Multiples Metodos

Tarjetas, Nequi, PSE, Bancolombia, Daviplata, Puntos Colombia y mas.

🔒

Seguridad Bancaria

Firma SHA256, verificacion de webhooks, cumplimiento PCI DSS.

⚡

Pagos Asincronos

Webhooks para PSE, Nequi y otros metodos que requieren confirmacion.

🇨🇴

Colombia

Optimizado exclusivamente para el mercado colombiano en COP.

🧪

Sandbox Automatico

Credenciales de prueba automaticas para desarrollo y testing.

📧

Notificaciones

Alertas automaticas por email sobre el estado de los pagos.

Por que Wompi?

  • Respaldo de Bancolombia - Plataforma oficial del banco mas grande de Colombia
  • Sin costos de integracion - Solo pagas por transaccion exitosa
  • Metodos locales - Nequi, PSE, Daviplata y mas billeteras colombianas
  • Widget moderno - Experiencia de pago fluida y responsiva
  • Documentacion en espanol - Soporte y documentacion en tu idioma

Caracteristicas Principales

  • Soporte para ambientes Sandbox (pruebas) y Produccion
  • Widget de checkout integrado de Wompi
  • Procesamiento de pagos asincronos via webhooks
  • Notificaciones automaticas a usuarios por email
  • Registro completo de transacciones en base de datos
  • Cumplimiento GDPR para proteccion de datos personales
  • Soporte multiidioma (Espanol e Ingles)
  • Credenciales de prueba automaticas en Sandbox

Requisitos de Cuenta Wompi

  • Cuenta de comercio verificada en comercios.wompi.co

⚠️ Importante

Wompi es exclusivo para Colombia. Solo acepta pagos en Pesos Colombianos (COP) y requiere una cuenta bancaria colombiana para recibir los fondos.

Instalacion del Plugin

Metodo 1: Instalacion Manual

  1. Descarga el plugin

    Descarga el archivo ZIP desde el repositorio oficial o contacta a soporte@ingeweb.co

  2. Extrae los archivos

    Descomprime el archivo en el directorio de pasarelas de pago de Moodle:

    /tu-sitio-moodle/payment/gateway/wompi
  3. Verifica la estructura de archivos

    Asegurate de que la estructura sea correcta:

    payment/gateway/wompi/
├── classes/
│   ├── gateway.php           # Clase principal
│   ├── wompi_helper.php      # Helper de API
│   └── privacy/
│       └── provider.php      # GDPR
├── db/
│   ├── install.xml           # Estructura BD
│   └── messages.php          # Notificaciones
├── docs/
│   └── documentacion.html    # Esta guia
├── lang/
│   ├── en/paygw_wompi.php    # Ingles
│   └── es/paygw_wompi.php    # Espanol
├── pix/
│   └── icon.svg              # Icono
├── cancelled.php
├── CHANGELOG.md
├── lib.php
├── pay.php                   # Inicio de pago
├── process.php               # Procesa callback
├── README.md
├── version.php
└── webhook.php               # Recibe webhooks
  4. Ejecuta la instalacion en Moodle

    Accede como administrador y ve a:

    Administracion del sitio → Notificaciones

    Moodle detectara automaticamente el nuevo plugin y te guiara en la instalacion.

  5. Verifica la instalacion

    Confirma que el plugin aparece en:

    Administracion del sitio → Plugins → Pasarelas de pago → Gestionar pasarelas

Metodo 2: Via Git

# Navegar al directorio de pasarelas de pago
cd /ruta/a/moodle/payment/gateway

git clone https://github.com/ingeweb/moodle-paygw_wompi.git wompi

composer require ingeweb/moodle-paygw_wompi

✅ Verificacion de Instalacion

El plugin esta correctamente instalado si:

  • Aparece en la lista de pasarelas de pago
  • La tabla paygw_wompi_transactions existe en la base de datos
  • No hay errores en los logs de Moodle

Configuracion en Wompi

Antes de configurar el plugin en Moodle, necesitas obtener tus credenciales de Wompi.

Paso 1: Crear cuenta en Wompi

  1. Registrate en Wompi

    Ve a comercios.wompi.co y crea tu cuenta de comercio.

  2. Completa la verificacion

    Proporciona la documentacion requerida (RUT, camara de comercio, etc.)

  3. Configura tu cuenta bancaria

    Agrega la cuenta bancaria colombiana donde recibiras los fondos.

Paso 2: Obtener las Llaves de API

  1. Accede al Dashboard de Wompi

    Inicia sesion en comercios.wompi.co

  2. Ve a la seccion de llaves

    Navega a Configuracion → Llaves de API

  3. Copia las llaves

    Tendras disponibles las siguientes llaves:

Llave Formato Sandbox Formato Produccion Uso
Llave Publica pub_test_... pub_prod_... Iniciar transacciones
Llave Privada prv_test_... prv_prod_... Consultar transacciones
Llave de Integridad test_integrity_... prod_integrity_... Firmar transacciones
Llave de Eventos test_events_... prod_events_... Verificar webhooks

⚠️ Seguridad de las Llaves

  • Nunca compartas tus llaves privadas o de integridad
  • No las incluyas en codigo fuente publico
  • Usa las llaves correctas para cada ambiente (sandbox/produccion)
  • Regeneralas si sospechas que fueron comprometidas

Configuracion del Webhook

El webhook es esencial para procesar pagos asincronos como PSE, Nequi, Bancolombia Transfer, etc.

Que es un Webhook?

Un webhook es una URL en tu servidor que Wompi utiliza para notificarte cuando el estado de una transaccion cambia. Esto permite procesar pagos que no se confirman instantaneamente.

Configurar el Webhook en Wompi

  1. Accede al Dashboard de Wompi

    Inicia sesion en comercios.wompi.co

  2. Ve a la seccion de Eventos

    Navega a Configuracion → Eventos

  3. Agrega la URL del Webhook

    Ingresa la siguiente URL (reemplaza con tu dominio):

    https://tu-sitio-moodle.com/payment/gateway/wompi/webhook.php
  4. Activa el evento transaction.updated

    Selecciona el evento transaction.updated para recibir notificaciones de cambios de estado.

  5. Copia la Llave de Eventos

    Wompi te proporcionara una Llave de Eventos. Copia esta llave y agregala en la configuracion del plugin en Moodle.

💡 URL del Webhook

La URL exacta de tu webhook es:

https://[TU-DOMINIO]/payment/gateway/wompi/webhook.php

Verificar el Webhook

  1. Configura el ambiente Sandbox

    Asegurate de estar en modo Sandbox para pruebas.

  2. Realiza un pago de prueba con Nequi o PSE

    Estos metodos requieren el webhook para completar la transaccion.

  3. Verifica la inscripcion

    Si el usuario se inscribe automaticamente despues de confirmar el pago, el webhook funciona correctamente.

✅ Webhook Configurado Correctamente

Sabras que el webhook funciona si:

  • Los pagos con Nequi/PSE inscriben automaticamente al usuario
  • La transaccion en la BD cambia de PENDING a APPROVED/DELIVERED
  • El usuario recibe email de confirmacion

Guia para Administradores

Configurar Pago en un Curso

  1. Accede al curso

    Navega al curso donde deseas habilitar pagos.

  2. Ve a Metodos de inscripcion

    Accede a: Administracion del curso → Usuarios → Metodos de inscripcion

  3. Agrega inscripcion con pago

    Haz clic en "Agregar metodo" y selecciona "Inscripcion con pago"

  4. Configura el metodo de pago
    • Cuenta de pago: Selecciona la cuenta donde configuraste Wompi
    • Costo de inscripcion: Ingresa el precio en COP (ej: 50000 = $50.000)
    • Moneda: COP (Pesos Colombianos)
  5. Guarda los cambios

    El curso ahora requerira pago para inscribirse.

Monitorear Transacciones

En Moodle

  • Reportes de Pagos: Administracion del sitio → Reportes → Pagos
  • Logs del sistema: Administracion del sitio → Reportes → Logs
  • Base de datos: Tabla paygw_wompi_transactions

En Wompi

  • Dashboard: Seccion de Transacciones
  • Filtros: Por fecha, estado, referencia
  • Detalle: Informacion completa de cada pago

Estados de Transaccion

Estado Descripcion Accion
PENDING Pago iniciado, esperando confirmacion Esperar o verificar en Wompi
APPROVED Pago aprobado exitosamente Usuario inscrito automaticamente
DELIVERED Pago procesado y curso entregado Ninguna - completado
DECLINED Pago rechazado por el banco Usuario debe reintentar
ERROR Error en el procesamiento Revisar logs
VOIDED Transaccion anulada Ninguna

Guia para Estudiantes

Como Pagar e Inscribirse a un Curso

  1. Accede al curso

    Navega al curso que deseas tomar. Veras el precio y el boton de pago.

  2. Haz clic en "Pagar con Wompi"

    Se abrira el widget de pago de Wompi.

  3. Selecciona tu metodo de pago

    Elige entre tarjeta de credito, Nequi, PSE, Bancolombia, Daviplata, etc.

  4. Completa la informacion requerida

    Segun el metodo seleccionado, ingresa los datos solicitados.

  5. Confirma el pago

    Sigue las instrucciones especificas del metodo de pago.

  6. Espera la confirmacion

    Para pagos inmediatos, seras inscrito al instante. Para pagos asincronos (PSE, Nequi), espera unos minutos.

Metodos de Pago - Instrucciones

💳 Tarjeta de Credito/Debito

Ingresa el numero de tarjeta, fecha de vencimiento, CVV y nombre del titular. El pago se procesa instantaneamente.

📱 Nequi

Ingresa tu numero de celular registrado en Nequi. Recibiras una notificacion en la app para aprobar el pago.

🏦 PSE

Selecciona tu banco y seras redirigido al portal del banco para completar la transferencia.

🔄 Bancolombia Transfer

Usa la app de Bancolombia para escanear el codigo QR o transferir directamente.

✅ Confirmacion de Pago

Una vez aprobado el pago:

  • Seras inscrito automaticamente al curso
  • Recibiras un email de confirmacion
  • Podras acceder inmediatamente al contenido del curso

Seguridad

Firma de Integridad SHA256

Todas las transacciones son firmadas para garantizar su integridad:

signature = SHA256(reference + amount_in_cents + currency + integrity_key)

Verificacion de Webhooks

Los webhooks son verificados usando la llave de eventos:

// Concatenar propiedades segun signature.properties
$signature_string = '';
foreach ($properties as $property) {
    $signature_string .= get_nested_value($event_data, $property);
}
$signature_string .= $timestamp . $events_key;
$calculated_signature = hash('sha256', $signature_string);

Mejores Practicas de Seguridad

  • Usa HTTPS siempre - Obligatorio para procesar pagos
  • Protege tus llaves - Nunca las compartas o publiques
  • Configura el webhook - Para pagos asincronos seguros
  • Monitorea transacciones - Revisa regularmente los logs
  • Actualiza el plugin - Mantente al dia con las actualizaciones

🔒 Cumplimiento de Seguridad

  • PCI DSS: Wompi cumple con los estandares de seguridad de la industria de tarjetas
  • GDPR: El plugin incluye provider de privacidad para proteccion de datos
  • Sin datos sensibles: El plugin no almacena numeros de tarjeta ni datos sensibles

Solucion de Problemas

El pago no se procesa
  1. Verifica que las llaves sean correctas para el ambiente seleccionado
  2. Confirma que los prefijos coincidan (pub_test_ para Sandbox, pub_prod_ para Produccion)
  3. Revisa los logs de Moodle en Administracion → Reportes → Logs
  4. Verifica la conexion a Internet del servidor
Error de firma de integridad
  1. Verifica que la Llave de Integridad sea exacta (sin espacios)
  2. Confirma que estas usando la llave del ambiente correcto
  3. Regenera la llave en el panel de Wompi si es necesario
El usuario no se inscribe despues del pago
  1. Verifica que el webhook este configurado correctamente
  2. Confirma que la URL del webhook sea accesible (HTTPS)
  3. Revisa que la Llave de Eventos este configurada en el plugin
  4. Para pagos con tarjeta (inmediatos), verifica la redireccion
  5. Revisa la tabla paygw_wompi_transactions para ver el estado
El widget de Wompi no carga
  1. Verifica que tu sitio use HTTPS
  2. Revisa la consola del navegador (F12) por errores
  3. Asegurate de que no haya bloqueadores de scripts o ad-blockers
  4. Confirma que la Llave Publica sea valida
Transaccion queda en PENDING indefinidamente
  1. Esto es normal para metodos asincronos si el webhook no esta configurado
  2. Configura el webhook siguiendo la seccion 6 de esta guia
  3. Verifica manualmente el estado en el dashboard de Wompi

Referencia de API

Clase wompi_helper

use paygw_wompi\wompi_helper;

// Crear instancia
$helper = new wompi_helper($publickey, $privatekey, $integritykey, $environment, $eventskey);

// Generar firma de integridad
$signature = $helper->generate_integrity_signature($reference, $amount_in_cents, $currency);

// Obtener transaccion de Wompi
$transaction = $helper->get_transaction($transaction_id);

// Verificar firma de webhook
$valid = $helper->verify_webhook_signature($event_data, $signature);

// Entregar orden (inscribir usuario)
$helper->deliver_order($component, $paymentarea, $itemid, $userid, $cost, $currency);

Clase gateway

use paygw_wompi\gateway;

// Obtener monedas soportadas
$currencies = gateway::get_supported_currencies(); // ['COP']

// Obtener URL de la API
$url = gateway::get_api_url('sandbox'); // https://sandbox.wompi.co/v1

// Obtener credenciales de prueba
$test_creds = gateway::get_test_credentials();

// Obtener tarjetas de prueba
$test_cards = gateway::get_test_cards();

// Crear helper desde configuracion (con auto-fallback a sandbox)
$helper = gateway::create_helper_from_config($config);

Constantes de Estado

wompi_helper::STATUS_APPROVED   // 'APPROVED'
wompi_helper::STATUS_DECLINED   // 'DECLINED'
wompi_helper::STATUS_PENDING    // 'PENDING'
wompi_helper::STATUS_VOIDED     // 'VOIDED'
wompi_helper::STATUS_ERROR      // 'ERROR'
