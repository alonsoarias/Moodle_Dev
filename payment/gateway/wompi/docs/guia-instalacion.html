Introducción

El plugin paygw_wompi permite integrar la pasarela de pago Wompi en tu sitio Moodle, facilitando el cobro de cursos y contenido educativo a estudiantes en Colombia.

💳

Múltiples Métodos

Tarjetas, PSE, Nequi, Bancolombia, Daviplata y más

🔒

Seguro

Firma SHA256 y verificación de webhooks

⚡

Automático

Inscripción automática al confirmar pago

🌐

Bilingüe

Soporte en Español e Inglés

1. Requisitos Previos

Requisitos del Sistema

Componente Versión Mínima Recomendada
Moodle 4.1 4.3+
PHP 7.4 8.1+
Base de datos MySQL 5.7 / PostgreSQL 12 MySQL 8.0 / PostgreSQL 14

Requisitos de Wompi

  • Cuenta de comercio activa en Wompi Colombia
  • Documentación del comercio aprobada
  • Acceso al Dashboard de Wompi
⚠️ Importante: Para ambiente de producción, tu sitio Moodle DEBE tener un certificado SSL válido (HTTPS).

2. Instalación del Plugin

1 Descargar el plugin

Descarga el archivo ZIP del plugin desde el repositorio oficial o copia la carpeta wompi directamente.

2 Subir al servidor

Coloca la carpeta del plugin en la ruta:

/tu-moodle/payment/gateway/wompi/

La estructura debe verse así:

payment/
└── gateway/
    └── wompi/
        ├── classes/
        ├── db/
        ├── lang/
        ├── pix/
        ├── cancelled.php
        ├── pay.php
        ├── process.php
        ├── version.php
        └── webhook.php
3 Instalar en Moodle
  1. Accede a tu sitio Moodle como Administrador
  2. Navega a Administración del sitio → Notificaciones
  3. Moodle detectará el nuevo plugin automáticamente
  4. Haz clic en "Actualizar base de datos de Moodle ahora"
  5. Espera a que se complete la instalación
✅ Éxito: Verás el mensaje "Wompi" en la lista de plugins instalados.

3. Configuración en Wompi

1 Acceder al Dashboard de Wompi

Ingresa a comercios.wompi.co con tus credenciales de comercio.

2 Obtener las Llaves de API
  1. En el menú lateral, haz clic en Configuración
  2. Selecciona Llaves de API
  3. Encontrarás las llaves para ambos ambientes (Sandbox y Producción)

Llaves necesarias:

Llave Formato Sandbox Formato Producción
Llave Pública pub_test_XXXXX pub_prod_XXXXX
Llave Privada prv_test_XXXXX prv_prod_XXXXX
Llave de Integridad Cadena alfanumérica (igual para ambos)
Llave de Eventos Cadena alfanumérica (opcional, para webhooks)
🔐 Seguridad: NUNCA compartas tu Llave Privada. Mantenla segura y solo úsala en el servidor.
3 Copiar las Llaves

Copia cada llave haciendo clic en el ícono de copiar. Guárdalas temporalmente en un lugar seguro para usarlas en la configuración de Moodle.

4. Configuración en Moodle

1 Crear una Cuenta de Pago
  1. Ve a Administración del sitio → Plugins → Pasarelas de pago → Gestionar cuentas de pago
  2. Haz clic en "Crear cuenta de pago"
  3. Ingresa un nombre descriptivo (ej: "Pagos Wompi Colombia")
  4. Opcionalmente, agrega un ID de cuenta para referencia
  5. Haz clic en "Guardar cambios"
2 Habilitar la Pasarela Wompi
  1. En la cuenta de pago creada, haz clic en "Gestionar pasarelas de pago"
  2. Busca "Wompi" en la lista
  3. Haz clic en el ícono de engranaje (⚙️) para configurar
3 Configurar las Credenciales

Completa el formulario de configuración:

Campo Descripción
Habilitado Marca esta casilla para activar Wompi
Ambiente Selecciona "Sandbox" para pruebas o "Producción" para pagos reales
Llave Pública Pega la llave pública de Wompi
Llave Privada Pega la llave privada de Wompi
Llave de Integridad Pega la llave de integridad
Llave de Eventos (Opcional) Para verificación de webhooks
Métodos de Pago Selecciona los métodos que deseas ofrecer
Recopilar datos del cliente Marca para pre-llenar email y nombre del usuario
💡 Consejo: Comienza con el ambiente Sandbox para hacer pruebas antes de pasar a Producción.
4 Configurar un Curso con Pago
  1. Accede al curso que deseas monetizar
  2. Ve a Participantes → Métodos de inscripción
  3. En el menú desplegable, selecciona "Inscripción con pago"
  4. Configura:
    • Cuenta de pago: Selecciona la cuenta con Wompi
    • Costo de inscripción: Ingresa el monto en COP
    • Moneda: COP (Peso Colombiano)
    • Rol asignado: Estudiante
  5. Haz clic en "Agregar método"

5. Configuración del Webhook

⚠️ Importante: El webhook es ESENCIAL para procesar pagos asíncronos como PSE, Nequi y Bancolombia. Sin él, los usuarios no serán inscritos automáticamente con estos métodos.
1 Obtener la URL del Webhook

La URL del webhook de tu sitio Moodle es:

https://tu-sitio-moodle.com/payment/gateway/wompi/webhook.php

Reemplaza tu-sitio-moodle.com con el dominio real de tu sitio.

2 Configurar en Wompi
  1. En el Dashboard de Wompi, ve a Configuración → Eventos
  2. Haz clic en "Agregar endpoint"
  3. Pega la URL del webhook
  4. Selecciona el evento "transaction.updated"
  5. Guarda los cambios
  6. Copia la Llave de Eventos generada
3 Agregar Llave de Eventos en Moodle
  1. Regresa a la configuración de Wompi en Moodle
  2. Pega la Llave de Eventos en el campo correspondiente
  3. Guarda los cambios

Eventos Soportados

Evento Descripción Acción en Moodle
transaction.updated Cambio de estado en transacción Inscribe al usuario si el pago es aprobado

Flujo de Prueba

1 Probar como estudiante
  1. Cierra sesión como administrador
  2. Inicia sesión con una cuenta de estudiante de prueba
  3. Accede al curso con pago configurado
  4. Haz clic en "Inscribirse" o "Pagar"
  5. Selecciona Wompi como método de pago
  6. Completa el pago con datos de prueba
  7. Verifica que la inscripción se complete

7. Solución de Problemas

Problemas Comunes

! Error: "Llave pública inválida"

Causa: La llave no corresponde al ambiente seleccionado.

Solución:

  • Para Sandbox, la llave debe comenzar con pub_test_
  • Para Producción, debe comenzar con pub_prod_
! El usuario no se inscribe después del pago

Causa: Webhook no configurado o inaccesible.

Solución:

  1. Verifica que el webhook esté configurado en Wompi
  2. Confirma que la URL sea accesible desde Internet
  3. Asegúrate de que la Llave de Eventos esté configurada
  4. Revisa los logs de Moodle para errores
! Error de firma de integridad

Causa: Llave de integridad incorrecta o modificada.

Solución:

  • Copia nuevamente la llave desde el Dashboard de Wompi
  • Asegúrate de no incluir espacios adicionales
  • Verifica que la llave sea la correcta para el ambiente
! El widget de pago no carga

Causa: Problema de carga del script de Wompi.

Solución:

  • Verifica la conexión a Internet
  • Asegúrate de que no haya bloqueadores de scripts
  • Revisa la consola del navegador para errores

Ver Logs de Moodle

Para diagnosticar problemas, revisa los logs:

  1. Ve a Administración del sitio → Servidor → Registros
  2. Filtra por paygw_wompi
  3. Revisa los mensajes de error recientes
