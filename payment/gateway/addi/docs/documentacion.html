💳 Plugin de Pagos Addi

Compra Ahora, Paga Después (BNPL) para Moodle - Colombia

📋 Descripción General

El plugin paygw_addi permite integrar el servicio de financiamiento Addi en tu plataforma Moodle. Addi es un servicio colombiano de "Buy Now, Pay Later" (BNPL) que permite a los estudiantes dividir el pago de sus cursos en cuotas convenientes.

¿Qué es Addi?

  • Compra Ahora, Paga Después: Los estudiantes pueden acceder inmediatamente al curso y pagar en cuotas
  • Aprobación Rápida: Proceso de verificación de crédito en minutos
  • Sin Tarjeta de Crédito: No requiere tarjeta de crédito tradicional
  • Cuotas Flexibles: Planes de pago adaptados a las necesidades del estudiante

Moneda Soportada

  • COP Peso Colombiano

Límites de Monto

  • Mínimo: $50,000 COP (configurable)
  • Máximo: $5,000,000 COP (configurable)

🚀 Requisitos

  • Moodle 4.1 o superior
  • PHP 8.0 o superior
  • Cuenta comercial con Addi
  • SSL/HTTPS habilitado en tu servidor
  • Contrato de aliado comercial con Addi

📦 Instalación

1Descargar el Plugin

Copia la carpeta addi en el directorio:

/payment/gateway/addi

2Instalar desde Moodle

  1. Accede como administrador a tu sitio Moodle
  2. Ve a Administración del sitio → Notificaciones
  3. Sigue el asistente de instalación de plugins

3Habilitar el Plugin

  1. Ve a Administración del sitio → Plugins → Pasarelas de pago → Gestionar pasarelas de pago
  2. Activa el plugin "Addi"

🔑 Obtener Credenciales de Addi

Proceso de Registro

  1. Contacta al equipo comercial de Addi en co.addi.com
  2. Completa el proceso de onboarding como aliado comercial
  3. Una vez aprobado, recibirás:
    • Client ID
    • Client Secret
    • Ally Slug (identificador único de tu comercio)
ℹ️ Nota: Addi proporciona credenciales separadas para los ambientes de Sandbox y Producción.

Ambiente Sandbox (Pruebas)

El ambiente de sandbox permite probar la integración sin procesar transacciones reales. Las solicitudes de financiamiento serán simuladas.

Ambiente Producción

Una vez completadas las pruebas en sandbox, Addi habilitará tus credenciales de producción.

⚙️ Configuración

Crear una Cuenta de Pago

  1. Ve a Administración del sitio → Plugins → Inscripciones → Gestionar cuentas de pago
  2. Haz clic en "Crear cuenta de pago"
  3. Completa el nombre y selecciona la moneda (COP)

Configurar Addi en la Cuenta

  1. En la cuenta de pago, haz clic en "Addi" bajo pasarelas de pago
  2. Activa la pasarela
  3. Configura los siguientes campos:
Campo Descripción
Ambiente Selecciona "Sandbox" para pruebas o "Producción" para transacciones reales
Client ID Tu identificador de cliente proporcionado por Addi
Client Secret Tu secreto de cliente proporcionado por Addi
Ally Slug Tu identificador único de comercio en Addi
Monto Mínimo Monto mínimo permitido para pagos con Addi (default: 50,000 COP)
Monto Máximo Monto máximo permitido para pagos con Addi (default: 5,000,000 COP)

🔗 Configuración de URLs en Addi

Debes configurar las siguientes URLs en tu panel de Addi:

URL de Redirección

https://tu-sitio.com/payment/gateway/addi/response.php

URL de Webhook

https://tu-sitio.com/payment/gateway/addi/webhook.php
ℹ️ Nota: Reemplaza tu-sitio.com con el dominio real de tu instalación de Moodle.

🔄 Flujo de Pago

  1. El estudiante selecciona un curso con inscripción de pago
  2. Selecciona "Addi" como método de pago
  3. Es redirigido al portal de Addi
  4. Completa el proceso de solicitud de financiamiento
  5. Addi evalúa la solicitud y notifica el resultado
  6. Si es aprobado, el estudiante se inscribe automáticamente al curso
  7. El estudiante paga las cuotas directamente a Addi

📊 Estados de Transacción

Estado Descripción
INITIATED Solicitud iniciada pero no enviada a Addi
PENDING Solicitud enviada a Addi, en proceso de evaluación
APPROVED Financiamiento aprobado, estudiante inscrito
REJECTED Solicitud de financiamiento rechazada
CANCELLED Solicitud cancelada por el usuario
EXPIRED Solicitud expirada por inactividad

⏰ Tareas Programadas

El plugin incluye las siguientes tareas programadas:

Verificar Transacciones Pendientes

  • Se ejecuta cada 30 minutos
  • Consulta el estado de transacciones pendientes en Addi
  • Completa inscripciones si el financiamiento fue aprobado

Limpiar Transacciones Expiradas

  • Se ejecuta diariamente a las 4:00 AM
  • Elimina transacciones abandonadas
  • Marca transacciones pendientes antiguas como expiradas

📧 Plantillas de Email

El plugin permite personalizar los emails de notificación. Puedes usar los siguientes placeholders:

Placeholder Descripción
{firstname} Nombre del usuario
{fullname} Nombre completo del usuario
{amount} Monto del pago con moneda
{currency} Código de moneda
{orderid} ID de orden/referencia

🔒 Seguridad

  • OAuth 2.0: Autenticación segura con el API de Addi
  • HTTPS Requerido: Todas las comunicaciones usan SSL/TLS
  • Webhooks Verificados: Se valida la autenticidad de las notificaciones
  • Tokens con Expiración: Los tokens de acceso tienen tiempo de vida limitado

❓ Solución de Problemas

Error "Monto fuera de límites"

  • Verifica que el precio del curso esté dentro de los límites de Addi
  • Ajusta los límites mínimo/máximo en la configuración del plugin

La solicitud no se procesa

  • Verifica que las credenciales (Client ID, Client Secret, Ally Slug) sean correctas
  • Asegúrate de usar las credenciales del ambiente correcto
  • Revisa los logs de Moodle para errores de API

El estudiante no se inscribe después de la aprobación

  • Verifica que el webhook esté configurado correctamente en Addi
  • Ejecuta manualmente la tarea "Verificar transacciones pendientes"
  • Revisa los logs para errores de entrega
