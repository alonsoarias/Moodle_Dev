🛒 Plugin de Pagos ePayco

Pasarela de pagos ePayco para Moodle - Colombia

📋 Descripción General

El plugin paygw_epayco permite integrar la pasarela de pagos ePayco en tu plataforma Moodle, facilitando el cobro de cursos y contenido usando los métodos de pago más populares de Colombia.

Métodos de Pago Soportados

  • Tarjetas de Crédito: Visa, MasterCard, American Express, Diners
  • Tarjetas Débito: Con soporte 3D Secure
  • PSE: Transferencias bancarias
  • Efectivo: Baloto, Efecty, Gana
  • Billeteras Digitales: Daviplata, Nequi

Monedas Soportadas

  • COP Peso Colombiano
  • USD Dólar Estadounidense

🚀 Requisitos

  • Moodle 4.1 o superior
  • PHP 8.0 o superior
  • Cuenta comercial en ePayco
  • SSL/HTTPS habilitado en tu servidor

📦 Instalación

1Descargar el Plugin

Copia la carpeta epayco en el directorio:

/payment/gateway/epayco

2Instalar desde Moodle

  1. Accede como administrador a tu sitio Moodle
  2. Ve a Administración del sitio → Notificaciones
  3. Sigue el asistente de instalación de plugins

3Habilitar el Plugin

  1. Ve a Administración del sitio → Plugins → Pasarelas de pago → Gestionar pasarelas de pago
  2. Activa el plugin "ePayco"

🔑 Obtener Credenciales de ePayco

Para Ambiente de Pruebas (Sandbox)

  1. Crea una cuenta en epayco.com
  2. En el panel de ePayco, ve a Configuración → Integraciones → Llaves API
  3. Copia las credenciales de prueba:
    • P_CUST_ID_CLIENTE
    • P_KEY
    • PUBLIC_KEY
    • PRIVATE_KEY
ℹ️ Nota: Las credenciales de prueba son únicas para cada comercio. Debes crear tu cuenta en ePayco para obtener tus propias credenciales de sandbox.

Para Ambiente de Producción

  1. Completa el proceso de verificación con ePayco
  2. Activa tu cuenta comercial
  3. Obtén tus credenciales de producción desde el panel de ePayco
⚠️ Importante: Nunca uses credenciales de producción en ambientes de desarrollo o prueba.

⚙️ Configuración

Crear una Cuenta de Pago

  1. Ve a Administración del sitio → Plugins → Inscripciones → Gestionar cuentas de pago
  2. Haz clic en "Crear cuenta de pago"
  3. Completa el nombre y selecciona la moneda (COP o USD)

Configurar ePayco en la Cuenta

  1. En la cuenta de pago, haz clic en "ePayco" bajo pasarelas de pago
  2. Activa la pasarela
  3. Configura los siguientes campos:
Campo Descripción
Ambiente Selecciona "Pruebas" para sandbox o "Producción" para transacciones reales
P_CUST_ID_CLIENTE Tu ID de cliente de ePayco
P_KEY Tu llave P_KEY de ePayco
PUBLIC_KEY Tu llave pública de ePayco
PRIVATE_KEY Tu llave privada de ePayco
Idioma Idioma de la página de pago (Español/Inglés)
Recopilar datos del cliente Pre-llena información del usuario en el checkout

🔗 Configuración de URLs en ePayco

Debes configurar las siguientes URLs en tu panel de ePayco:

URL de Confirmación (Callback Server-to-Server)

https://tu-sitio.com/payment/gateway/epayco/confirmation.php

URL de Respuesta (Retorno del Usuario)

https://tu-sitio.com/payment/gateway/epayco/response.php
ℹ️ Nota: Reemplaza tu-sitio.com con el dominio real de tu instalación de Moodle.

📧 Plantillas de Email

El plugin permite personalizar los emails de notificación enviados a los usuarios. Puedes usar los siguientes placeholders:

Placeholder Descripción
{firstname} Nombre del usuario
{fullname} Nombre completo del usuario
{amount} Monto del pago con moneda
{currency} Código de moneda
{orderid} ID de orden/referencia

🔄 Flujo de Pago

  1. El usuario selecciona un curso con inscripción de pago
  2. Selecciona "ePayco" como método de pago
  3. Se abre el widget de ePayco con los datos del pago
  4. El usuario completa el pago en ePayco
  5. ePayco envía confirmación al servidor (callback)
  6. El usuario es redirigido a la página de respuesta
  7. Si el pago es exitoso, el usuario se inscribe automáticamente

📊 Estados de Transacción

Código Estado Descripción
1 Aprobada Transacción aprobada exitosamente
2 Rechazada Transacción rechazada
3 Pendiente Transacción pendiente de confirmación
4 Fallida Transacción fallida

⏰ Tareas Programadas

El plugin incluye las siguientes tareas programadas:

Verificar Transacciones Pendientes

  • Se ejecuta cada 15 minutos
  • Consulta el estado de transacciones pendientes en ePayco
  • Completa inscripciones si el pago fue aprobado

Limpiar Transacciones Expiradas

  • Se ejecuta diariamente a las 3:00 AM
  • Elimina transacciones abandonadas (iniciadas pero no completadas)
  • Limpia transacciones fallidas antiguas

🔒 Seguridad

  • Verificación de Firma: Todas las transacciones se validan usando firma SHA-256
  • HTTPS Requerido: El plugin requiere SSL/TLS para la comunicación segura
  • Validación de Montos: Se verifica que el monto pagado coincida con el esperado
  • Protección CSRF: Implementada en todas las acciones de usuario

❓ Solución de Problemas

El pago no se confirma automáticamente

  • Verifica que la URL de confirmación esté correctamente configurada en ePayco
  • Asegúrate de que tu servidor pueda recibir peticiones POST externas
  • Revisa los logs de Moodle para errores de callback

Error de firma inválida

  • Verifica que las credenciales (P_CUST_ID_CLIENTE, P_KEY) sean correctas
  • Asegúrate de usar las credenciales del ambiente correcto (test vs producción)

El usuario no se inscribe después del pago

  • Ejecuta manualmente la tarea "Verificar transacciones pendientes"
  • Revisa los logs para errores de entrega
  • Verifica que el curso tenga inscripción por pago configurada
