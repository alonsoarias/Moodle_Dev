INTEB Chat v3.6.1

Asistente de IA con OpenAI para Moodle

INTEB Chat es un modulo de actividad para Moodle que integra asistentes de inteligencia artificial basados en la API de OpenAI directamente en sus cursos. Permite a estudiantes y profesores interactuar con asistentes de IA personalizados para apoyo educativo, tutoria y aprendizaje interactivo.

IA Conversacional

Interacciones naturales con modelos GPT de OpenAI, incluyendo GPT-4o, GPT-4.1 y modelos de razonamiento.

Soporte de Audio

Entrada por voz y respuestas de audio con multiples voces disponibles para una experiencia inmersiva.

Conversaciones Persistentes

Historial de conversaciones guardado para que los usuarios puedan retomar donde dejaron.

Analiticas Detalladas

Reportes de uso por curso, usuario e instancia con seguimiento de tokens.

Control de Uso

Limites de tokens configurables por usuario con periodos personalizables.

Personalizacion

Mascotas animadas, temas claro/oscuro y nombres personalizables para el asistente.

Requisitos del Sistema

Componente Requisito Minimo Recomendado
Moodle Version 4.1 (2022112800) 4.3 o superior
PHP Version 8.0 PHP 8.1 o superior

Extension OpenSSL Requerida para encriptacion de claves API

Clave API Requerida: Necesita una cuenta de OpenAI con credito disponible y una clave API valida. Obtenga la suya en platform.openai.com/api-keys

Permisos Necesarios

  • Acceso de administrador al sitio Moodle
  • Permisos para instalar modulos de actividad
  • Conexion a Internet desde el servidor hacia api.openai.com

Instalacion Paso a Paso

1

Descargar el Plugin

Obtenga el archivo ZIP del plugin mod_intebchat proporcionado por Ingeweb.

2

Subir al Servidor

Extraiga el contenido del ZIP y copie la carpeta intebchat al directorio:

/path/to/moodle/mod/intebchat

O use el instalador de plugins de Moodle: Administracion del sitio → Plugins → Instalar plugins

3

Ejecutar la Instalacion

Acceda a su sitio Moodle como administrador y vaya a:

Administracion del sitio → Notificaciones

Moodle detectara el nuevo plugin y le pedira que complete la instalacion.

4

Configurar Clave API

Sera redirigido a la pagina de configuracion. Ingrese su clave API de OpenAI (sk-...).

Captura: Pantalla de notificaciones de Moodle mostrando la instalacion del plugin

Listo! Una vez completada la instalacion, podra agregar actividades INTEB Chat en cualquier curso.

Guia para Administradores

Reporte a Nivel de Sitio

Acceda a: Administracion del sitio → Informes → Reporte de INTEB Chat del Sitio

El reporte incluye:

  • Total de mensajes, usuarios y cursos activos
  • Uso de tokens (prompt y completion)
  • Desglose por curso
  • Actividad por usuario
  • Filtros por periodo (hoy, 7 dias, 30 dias, ano, todo)
  • Exportacion a CSV

Captura: Dashboard de reportes con estadisticas de uso

Gestion de Capacidades

El plugin define las siguientes capacidades:

Capacidad Descripcion Roles por Defecto
mod/intebchat:view Ver y usar el chat Todos
mod/intebchat:addinstance Agregar actividad al curso Profesor, Manager
mod/intebchat:viewstudentconversations Ver conversaciones de estudiantes Profesor, Manager
mod/intebchat:viewanalytics Ver analiticas del curso Profesor, Manager
mod/intebchat:viewsitereport Ver reportes a nivel de sitio Manager

Tarea Programada

El plugin incluye una tarea de limpieza que se ejecuta diariamente a las 3:00 AM:

  • Elimina conversaciones inactivas segun el periodo de retencion configurado
  • Limpia registros de uso de tokens antiguos

Backup y Restauracion

El plugin soporta completamente el sistema de backup de Moodle 2:

  • Configuracion de instancia
  • Logs de conversaciones (si se incluyen datos de usuario)
  • Historial de conversaciones

Configurar la Actividad

Preguntas Frecuentes

Puedo usar mi propia clave API de OpenAI?

Si, el plugin requiere su propia clave API de OpenAI. Puede obtener una en platform.openai.com. Los costos de uso de la API son facturados directamente por OpenAI.

Que modelos de IA estan disponibles?

El plugin soporta todos los modelos actuales de OpenAI incluyendo:

  • GPT-5 Series (mas recientes)
  • GPT-4.1 Series (recomendado para balance calidad/costo)
  • GPT-4o (multimodal)
  • Modelos de razonamiento (o1, o3, o4)
Las conversaciones son privadas?

Si, cada estudiante solo puede ver sus propias conversaciones. Los profesores pueden ver las conversaciones de estudiantes de su curso si tienen el permiso correspondiente. Los administradores pueden ver todas las conversaciones.

Hay limite de uso?

El administrador puede configurar limites de tokens por usuario. Cuando se alcanza el limite, el usuario debera esperar al siguiente periodo (hora, dia, semana o mes) para continuar usando el chat.

Funciona en dispositivos moviles?

Si, la interfaz es completamente responsiva y funciona en telefonos y tablets. El panel lateral se oculta automaticamente en pantallas pequenas y puede abrirse con el boton de menu.

Puedo personalizar las respuestas del asistente?

Si, use el campo "Instrucciones" en la configuracion de la actividad para definir el comportamiento del asistente. Puede especificar su rol, tono, restricciones de tema, y mas.

El plugin envia datos fuera del servidor?

Si, los mensajes se envian a la API de OpenAI para su procesamiento. Las conversaciones pueden almacenarse localmente en su servidor Moodle si habilita el registro de conversaciones.

Solucion de Problemas Comunes

Error: "Clave API no configurada"

Causa: No se ha configurado la clave API de OpenAI.
Solucion: Vaya a Administracion del sitio → Plugins → INTEB Chat y configure su clave API.

Error: "La solicitud ha excedido el tiempo de espera"

Causa: La API de OpenAI esta tardando demasiado en responder.
Solucion:
  • Intente nuevamente en unos minutos
  • Use un modelo mas rapido como GPT-4o-mini
  • Reduzca la longitud maxima de respuesta

Error: "Limite de tokens excedido"

Causa: El usuario ha alcanzado su limite de uso.
Solucion:
  • Espere al siguiente periodo de reinicio
  • Contacte al administrador para aumentar el limite

El audio no funciona

Posibles causas:
  • El audio no esta habilitado globalmente
  • El navegador no tiene permisos de microfono
  • El sitio no usa HTTPS (requerido para grabacion de audio)
Solucion: Verifique la configuracion global y los permisos del navegador.

Las conversaciones no se guardan

Causa: La opcion "Persistir conversacion" esta desactivada.
Solucion: Active la opcion en la configuracion de la actividad (modo Assistant) o en la configuracion global.

Error al instalar el plugin

Posibles causas:
  • Verifique los requisitos de version de Moodle (4.1+) y PHP (8.0+)
  • Asegurese de que la carpeta tenga los permisos correctos
  • Compruebe que todos los archivos se copiaron correctamente
  • Revise los logs del servidor por errores de base de datos
