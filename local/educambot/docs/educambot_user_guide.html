EducamBot v3.8.2

Chatbot Inteligente para Moodle

EducamBot es un asistente virtual integrado en Moodle que proporciona ayuda automatizada a estudiantes, profesores y administradores. El chatbot responde preguntas frecuentes, guía a los usuarios en la plataforma y ofrece acceso rápido a información relevante del curso.

Respuestas Inteligentes

Sistema de reglas avanzado con detección de intención y coincidencia flexible.

Personalizable

Temas visuales, mascotas animadas e iconos configurables.

Accesos Rápidos

Comandos dinámicos para tareas, calificaciones, calendario y más.

Multi-idioma

Soporte para español e inglés con detección automática.

Requisitos Previos

Requisitos del Sistema

Componente Requisito
Moodle Versión 4.0 o superior (compatible hasta 4.5)
PHP Versión 7.4 o superior (recomendado PHP 8.x)
Base de datos MySQL, PostgreSQL, MariaDB u Oracle
Navegador JavaScript habilitado (Chrome, Firefox, Safari, Edge)

Permisos Necesarios

  • Acceso de administrador al sitio Moodle
  • Permisos para instalar plugins locales
  • Acceso FTP o al sistema de archivos del servidor (para instalación manual)

Instalación Paso a Paso

1

Descargar el Plugin

Obtenga el archivo ZIP del plugin local_educambot proporcionado por Ingeweb.

2

Subir al Servidor

Extraiga el contenido del ZIP y copie la carpeta educambot al directorio:

/path/to/moodle/local/educambot
3

Ejecutar la Instalación

Acceda a su sitio Moodle como administrador y vaya a:

Administración del sitio → Notificaciones

Moodle detectará el nuevo plugin y le pedirá que complete la instalación.

4

Confirmar la Instalación

Haga clic en "Actualizar base de datos de Moodle ahora" para crear las tablas necesarias e importar la base de conocimientos inicial.

Captura: Pantalla de notificaciones de Moodle mostrando la instalación del plugin

¡Listo! Una vez completada la instalación, el widget del chatbot aparecerá automáticamente en todas las páginas de Moodle para usuarios autenticados.

Guía para Administradores

Gestionar Reglas de Respuesta

Acceda a: Administración → Plugins locales → EducamBot → Gestionar Reglas

Cada regla tiene los siguientes campos:

Campo Descripción
Patrón Pregunta principal que activa la regla
Palabras clave Términos adicionales para mejorar el matching (uno por línea)
Respuesta Texto que devuelve el bot (puede incluir HTML)
Categoría Organización temática de la regla
Tags Etiquetas para búsqueda y filtrado
Idioma Idioma de la regla (es/en)

Opciones Avanzadas de Reglas

  • Sensible al contexto: Usa información del curso actual en la respuesta
  • Respuesta dinámica: Contiene marcadores como {{user.firstname}}
  • Contexto requerido: Solo funciona en sitio/curso/actividad
  • Arquetipos permitidos: Filtrar por roles (student, teacher, manager, etc.)
  • Cursos: Limitar a cursos específicos por ID

Captura: Panel de gestión de reglas con filtros y acciones

Gestionar Categorías

Organice las reglas en categorías jerárquicas para facilitar la administración. Acceda a: EducamBot → Categorías

Gestionar Accesos Rápidos (Shortcuts)

Los shortcuts son comandos que muestran datos dinámicos de Moodle. Acceda a: EducamBot → Accesos Rápidos

Tipos de acciones disponibles:

Tipo Descripción
assignments Muestra tareas pendientes del usuario
grades Muestra calificaciones del curso
calendar Muestra próximos eventos
messages Muestra mensajes recientes
teachers Muestra profesores del curso
progress Muestra progreso en el curso
admin_* Accesos rápidos para administradores

Gestionar Temas Visuales

Personalice la apariencia del widget. Acceda a: EducamBot → Temas

Opciones de personalización:

  • Colores: primario, secundario, texto, fondo, burbujas de usuario y bot
  • Iconos del widget: predeterminado, emoji, Bootstrap Icons, imagen personalizada
  • Mascotas animadas: Robot, Búho, Clippy, Gato, Bombilla o SVG personalizado

Importar/Exportar Base de Conocimientos

Acceda a: EducamBot → Importar/Exportar

  • Exportar: Descarga toda la configuración en formato JSON
  • Importar: Carga reglas, categorías y opciones desde un archivo JSON
  • Opción para limpiar datos existentes antes de importar

Ver Reportes y Estadísticas

Acceda a: EducamBot → Reportes

Visualice métricas como:

  • Total de conversaciones
  • Preguntas respondidas vs. sin respuesta
  • Tasa de éxito y confianza promedio
  • Preguntas más frecuentes
  • Reglas que necesitan revisión (bajo feedback)

Guía para Usuarios Finales

Abrir el Chat

El widget de EducamBot aparece como un botón flotante en la esquina inferior derecha de la pantalla. Haga clic para abrir el chat.

Captura: Botón flotante del chatbot en la esquina de la pantalla

Hacer Preguntas

  1. Escriba su pregunta en el campo de texto
  2. Presione Enter o haga clic en el botón de enviar
  3. El bot responderá automáticamente
  4. Use los botones de respuesta rápida para explorar temas relacionados

Motor de Matching Inteligente

El algoritmo de coincidencia utiliza múltiples técnicas:

  • Coincidencia exacta y parcial de patrones
  • Matching de palabras clave con ponderación
  • Detección de intención (saludo, despedida, agradecimiento)
  • Tolerancia a errores tipográficos (distancia Levenshtein)
  • Coincidencia de sinónimos
  • N-gramas para frases parciales
  • Boost por feedback positivo

Preguntas Frecuentes

¿El chatbot usa inteligencia artificial?

EducamBot utiliza un sistema de reglas basado en patrones y procesamiento de lenguaje natural (NLP) local. No requiere conexión a servicios externos de IA ni envía datos fuera de su servidor Moodle.

¿Puedo personalizar las respuestas del bot?

Sí, los administradores pueden crear, editar y eliminar reglas de respuesta. También pueden importar bases de conocimiento personalizadas en formato JSON.

¿El plugin afecta el rendimiento de Moodle?

El impacto es mínimo. El widget se carga de forma asíncrona y las consultas AJAX son ligeras. La limpieza automática del historial ayuda a mantener la base de datos optimizada.

¿Se almacenan las conversaciones de los usuarios?

Sí, las conversaciones se almacenan para análisis y mejora del bot. El plugin incluye un Privacy Provider compatible con GDPR que permite exportar y eliminar datos de usuario bajo solicitud.

¿Funciona en dispositivos móviles?

Sí, el widget es completamente responsivo y se adapta a pantallas pequeñas. También funciona con la app oficial de Moodle.

¿Puedo desactivar el bot para ciertos usuarios?

Sí, el acceso al bot se controla mediante la capacidad local/educambot:use. Puede modificar los permisos por rol desde la administración de roles de Moodle.

Solución de Problemas Comunes

El widget no aparece

Posibles causas:
  • Verifique que el widget esté habilitado en la configuración
  • Confirme que el usuario tiene la capacidad local/educambot:use
  • Asegúrese de que no hay conflictos CSS con el tema de Moodle
  • Revise la consola del navegador por errores JavaScript

El bot no responde

Posibles causas:
  • Verifique que existan reglas activas en la base de conocimientos
  • Compruebe que el servicio AJAX (service.php) sea accesible
  • Revise los logs de Moodle por errores PHP
  • Confirme que la sesión del usuario no ha expirado

Las respuestas son incorrectas

Soluciones:
  • Revise y ajuste las palabras clave de las reglas
  • Agregue más variantes de patrones
  • Utilice el sistema de feedback para identificar reglas problemáticas
  • Consulte los reportes para ver preguntas sin respuesta

Error al instalar el plugin

Posibles causas:
  • Verifique los requisitos de versión de Moodle (4.0+) y PHP (7.4+)
  • Asegúrese de que la carpeta tenga los permisos correctos
  • Compruebe que todos los archivos se copiaron correctamente
  • Revise los logs del servidor por errores de base de datos

Problemas de rendimiento

Recomendaciones:
  • Configure un período de retención para el historial (ej: 3 meses)
  • Optimice las reglas eliminando duplicados
  • Desactive características no utilizadas (ej: mascotas, sonidos)
