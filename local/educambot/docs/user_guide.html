Introduccion

EducamBot es un asistente virtual inteligente disenado especificamente para plataformas Moodle. Permite a los usuarios obtener respuestas inmediatas a sus preguntas, acceder a informacion del curso y mejorar su experiencia de aprendizaje.

Version actual: 3.8.2
Compatibilidad: Moodle 4.0 o superior
Licencia: GNU GPL v3

Para que sirve EducamBot?

EducamBot actua como un primer nivel de soporte automatizado dentro de tu plataforma Moodle. Los estudiantes, profesores y administradores pueden hacer preguntas en lenguaje natural y obtener respuestas inmediatas basadas en una base de conocimiento configurable.

Beneficios principales

Soporte 24/7

Los usuarios obtienen respuestas inmediatas sin esperar a un agente humano.

Contexto Educativo

Disenado especificamente para entornos educativos con datos dinamicos de Moodle.

Totalmente Personalizable

Configura respuestas, apariencia, mascota e idiomas segun tus necesidades.

Analiticas Integradas

Reportes detallados para mejorar continuamente la base de conocimiento.

Instalacion

Metodo 1: Instalacion Manual

  1. Descarga el plugin
    Obtén el archivo ZIP del plugin desde el repositorio oficial o el marketplace de Moodle.
  2. Extrae los archivos
    Descomprime el archivo ZIP y renombra la carpeta a educambot.
  3. Sube al servidor
    Copia la carpeta educambot al directorio /local/ de tu instalacion de Moodle. 
    /tu-moodle/local/educambot/
  4. Actualiza la base de datos
    Inicia sesion como administrador en Moodle. Navega a:
    Administracion del sitio → Notificaciones
    Moodle detectara el nuevo plugin y procedera con la instalacion.
  5. Configura el plugin
    Despues de la instalacion, seras redirigido a la pagina de configuracion del plugin.

Metodo 2: Via Git

cd /tu-moodle/local/
git clone https://github.com/tu-repo/educambot.git

Luego accede a Administracion del sitio → Notificaciones para completar la instalacion.

Verificacion: Una vez instalado, deberas ver el widget de chat en la esquina inferior derecha de tu sitio Moodle (si tienes permisos).

Historial de Conversaciones

Opcion Descripcion
Habilitar historial Permite guardar y retomar conversaciones anteriores
Periodo de retencion Tiempo que se conservan los registros (1 semana a 1 año, o siempre)

Tiempo de Inactividad

Configura el tiempo (en milisegundos) antes de cerrar automaticamente el chat por inactividad. El valor predeterminado es 600000ms (10 minutos). Usa 0 para deshabilitarlo.

Feedback y Sonido

  • Habilitar feedback: Permite a los usuarios calificar las respuestas (me gusta/no me gusta)
  • Habilitar sonido: Reproduce un sonido de notificacion cuando el bot responde

Personaliza los colores del widget para que coincidan con la identidad visual de tu institucion.

Gestionar Temas

Accede a Administracion del sitio → Plugins → Plugins locales → EducamBot → Gestionar Temas

Crear un Tema

  1. Haz clic en "Agregar Tema"
  2. Ingresa un nombre descriptivo para el tema
  3. Configura los colores:
Color Uso Ejemplo

Color Secundario Estados hover, acentos #084a8a

Establecer Tema por Defecto

Desde la lista de temas, haz clic en "Establecer como predeterminado" junto al tema que deseas usar. Solo puede haber un tema activo a la vez.

Mascota del Chatbot

La mascota es un personaje animado que aparece junto al chat y reacciona a diferentes situaciones (pensando, exito, confusion, etc.). Ayuda a hacer la experiencia mas amigable.

Habilitar Mascota

En la configuracion del plugin, activa la opcion "Habilitar mascota".

Tipos de Mascota Disponibles

📎
Clippy

Un clasico clip de papel nostalgico al estilo del asistente de Microsoft.

🤖
Robot

Un robot amigable con antenas y ojos expresivos.

🦉
Buho

Un buho academico sabio, ideal para entornos educativos.

🐱
Gato

Un gato estudioso con lentes, simpatico y curioso.

💡
Bombilla

Una bombilla de ideas que representa inspiracion y ayuda.

🎨
Personalizada

Sube tu propio archivo SVG con animaciones personalizadas.

Estados de la Mascota

La mascota cambia de animacion segun el estado del bot:

  • Idle (inactivo): Flotacion suave mientras espera
  • Thinking (pensando): Movimiento de lado a lado, ojos parpadeando
  • Success (exito): Celebracion cuando encuentra una buena respuesta
  • Confused (confundido): Movimiento de confusion cuando no entiende
  • Greeting (saludo): Animacion de bienvenida al abrir el chat
  • Suggesting (sugiriendo): Rebote para llamar la atencion

Interaccion con la Mascota

Los usuarios pueden hacer clic en la mascota para ver preguntas populares. Tambien muestra sugerencias periodicas basadas en el rol del usuario.

Mascota Personalizada (SVG)

Si deseas usar tu propia mascota, sube un archivo SVG con las siguientes caracteristicas:

  • ViewBox de 80x80 pixeles
  • Elementos con IDs: body, eyes, arms
  • Tamano maximo: 50KB

Categorias

Las categorias te permiten organizar las reglas de respuesta en grupos logicos. Esto facilita la gestion cuando tienes muchas reglas.

Crear una Categoria

  1. Accede a Administracion → Plugins → EducamBot → Gestionar Categorias
  2. Haz clic en "Agregar Categoria"
  3. Ingresa:
    • Nombre: Nombre descriptivo (ej: "Inscripciones")
    • Descripcion: Breve explicacion del contenido
    • Categoria padre: Para crear jerarquias (opcional)
  4. Guarda los cambios

Jerarquia de Categorias

Puedes crear subcategorias seleccionando una "Categoria padre". Esto es util para organizar temas complejos: 

📁 Academico
   ├── 📁 Inscripciones
   ├── 📁 Calificaciones
   └── 📁 Certificados
📁 Tecnico
   ├── 📁 Acceso
   └── 📁 Problemas
Nota: No puedes eliminar una categoria que contenga reglas o subcategorias. Mueve o elimina el contenido primero.

Duplicar Reglas

Puedes duplicar una regla existente haciendo clic en el icono de duplicar. Esto crea una copia con todas sus opciones, util para crear variantes o traducciones.

Opciones de Respuesta Rapida

Las opciones son botones que aparecen despues de una respuesta del bot, permitiendo al usuario continuar la conversacion con un solo clic.

Agregar Opciones a una Regla

  1. Desde la lista de reglas, haz clic en "Opciones" junto a la regla
  2. Haz clic en "Agregar Opcion"
  3. Completa:
    • Texto del boton: Lo que vera el usuario (max 100 caracteres)
    • Regla destino: La regla que se activara al hacer clic
    • Icono: Emoji o icono Bootstrap (opcional)
    • Orden: Posicion del boton
  4. Guarda la opcion

Ejemplo de Flujo con Opciones

Usuario: Hola

Bot: Hola! En que puedo ayudarte?
     [📚 Ver mis tareas] [📊 Consultar calificaciones] [📅 Ver calendario]

Usuario: (clic en "Ver mis tareas")

Bot: Tus tareas pendientes son:
     - Tarea 1: Vence en 2 dias
     - Tarea 2: Vence en 5 dias
     [📝 Detalles de Tarea 1] [❓ Tengo un problema con una tarea]
Consejo: Usa opciones para guiar a los usuarios hacia las respuestas que necesitan sin que tengan que escribir. Esto mejora la experiencia del usuario.

Crear un Acceso Rapido

  1. Accede a Administracion → Plugins → EducamBot → Gestionar Accesos Rapidos
  2. Haz clic en "Agregar Acceso Rapido"
  3. Completa:
    • Nombre: Texto que vera el usuario (ej: "Mis tareas")
    • Descripcion: Texto descriptivo que aparece debajo
    • Icono: Icono Bootstrap (ej: bi-journal-check)
    • Palabras clave: Frases que activan este acceso (una por linea)
    • Tipo de accion: El dato de Moodle a mostrar
    • Arquetipos: Roles que pueden usar este acceso
Datos en contexto: Algunos accesos rapidos (como tareas o calificaciones) requieren que el usuario este dentro de un curso. Si no esta en un curso, el bot mostrara un mensaje indicando que debe navegar a un curso primero.

Importar y Exportar

Gestiona tu base de conocimiento exportandola como respaldo o importando desde otros sistemas.

Exportar Base de Conocimiento

Accede a Administracion → Plugins → EducamBot → Importar/Exportar

Formatos de Exportacion

  • JSON: Exportacion completa (categorias, reglas, opciones). Ideal para respaldos y migraciones.
  • CSV: Solo reglas. Ideal para edicion en hojas de calculo.

Importar Base de Conocimiento

  1. Prepara tu archivo JSON o CSV
  2. Selecciona el tipo de importacion:
    • Completa: Categorias, reglas y opciones
    • Solo reglas: Importa unicamente reglas
  3. Opcionalmente, marca "Borrar datos existentes" para limpiar todo antes de importar
  4. Sube el archivo y haz clic en "Importar"
Precaucion: La opcion "Borrar datos existentes" eliminara TODAS las categorias, reglas y opciones actuales. Esta accion no se puede deshacer. Haz un respaldo antes de usar esta opcion.

Plantillas de Ejemplo

Descarga las plantillas de ejemplo para conocer el formato correcto:

  • Plantilla JSON: Estructura completa con ejemplos

Uso del Chat

Esta seccion explica como los usuarios interactuan con el widget de chat.

Abrir el Chat

Haz clic en el boton flotante en la esquina inferior derecha de la pantalla. El boton tiene forma circular con el icono configurado del bot.

Enviar un Mensaje

  1. Escribe tu pregunta en el campo de texto
  2. Presiona Enter para enviar, o haz clic en el boton de enviar
  3. Usa Shift + Enter para agregar una nueva linea

Usar Accesos Rapidos

Debajo del mensaje de bienvenida aparecen botones de acciones rapidas. Haz clic en cualquiera para ejecutar esa accion inmediatamente.

Interactuar con la Mascota

  • Haz clic en la mascota para ver preguntas populares
  • La mascota muestra sugerencias periodicas basadas en tu rol
  • Cuando no encuentra una buena respuesta, muestra preguntas similares

Funciones del Encabezado

  • Exportar: Descarga la conversacion como archivo de texto
  • Limpiar: Borra el historial de la conversacion actual
  • Cerrar: Minimiza el chat

Dar Feedback

Debajo de cada respuesta del bot aparecen botones de y . Usa estos botones para indicar si la respuesta fue util.

Indicador de Tiempo de Inactividad

Si no interactuas con el chat durante un tiempo (configurable), aparecera una advertencia antes de cerrarse automaticamente. Haz clic en "Mantener abierto" para continuar.

Preguntas Frecuentes

Verifica lo siguiente:
  • El widget esta habilitado en la configuracion del plugin
  • Tu usuario tiene el permiso local/educambot:use
  • No estas en un layout embedded o de mantenimiento
  • JavaScript esta habilitado en tu navegador
  • No hay errores en la consola del navegador (F12)

  • Verifica que las palabras clave de tus reglas coincidan con lo que preguntas
  • Revisa si la regla tiene restricciones de rol o contexto
  • Consulta los reportes para ver si la pregunta fue registrada
